# CTFBox v0.1.2

本次更新重点完善 Misc 图片隐写能力，新增可实际执行的 LSB 与图片/文件隐写工作台。分析流程全部内置于 CTFBox，无需另外安装隐写工具。

## 新增功能

### LSB 隐写分析

- 新增自动分析和完整手动提取两种模式。
- 支持 RGBA、调色板索引、0-7 位平面及多通道组合。
- 支持逐行、逐列、反向、蛇形、MSB/LSB、位反相和字节反转等提取方式。
- 自动识别文本、常见文件头、ZIP/GZIP 归档及归档内 Flag。
- 候选结果按证据自动评分和排序，支持应用候选参数及导出原始数据。
- 疑似 Flag 新增一键复制按钮，直接复制完整 Flag。

### 图片/文件隐写分析

- 新增 PNG、JPEG、GIF、BMP、RIFF、PDF 文件结构分析。
- 支持 PNG 块与 CRC、JPEG 标记段、尾部附加数据检测和文件雕刻。
- 支持 EXIF、XMP、ICC、PNG 文本块及常见 GPS 元数据提取。
- 支持 ASCII、UTF-8、UTF-16、GB18030 字符串扫描。
- 支持 Base64、Hex、URL 内容的二次解码与 Flag 检测。
- 新增 RGBA、灰度、反相、自动拉伸和 8 个灰度位平面视图。
- 新增二维 FFT 频谱、频带能量和峰值分析。
- 新增基线 JPEG DCT 系数、AC 零值率和奇偶分布统计。

## 体验改进

- 隐写分析使用独立 Worker，长时间扫描支持取消。
- LSB 与图片/文件隐写任务相互隔离，切换工具后保留结果。
- 优化深色、浅色主题以及 1280、800、480 像素宽度下的工作区布局。
- 统一应用、安装器、Cargo 和前端包版本为 `0.1.2`。

## 支持范围说明

当前版本覆盖常见和多数中等难度图片隐写题。自定义加密、多文件关联，以及 F5、OutGuess、Steghide 等需要专用算法或口令的题目，可能只显示分析证据，仍需结合题目线索继续处理。

渐进式 JPEG 和算术编码 JPEG 会明确显示 DCT 解码不支持，不会生成伪造的系数统计。
