# SSTImap 汉化版使用说明

## 版本与目录

本目录是 SSTImap 的完整简体中文副本，可脱离 `Original` 启动。命令名、参数名、模板载荷和匹配数据保持原样，用户界面文本显示中文。

## 安装环境

```powershell
py -3 -m pip install -r ./CNversion/SSTImap-master/requirements.txt
```

建议在 Python 虚拟环境中安装 `requests`、`urllib3`、`beautifulsoup4` 和 `colorama` 等依赖。

## 启动

```powershell
# 从 CTFBox 根目录选择汉化版
./sstimap.cmd -cn --help

# 在 CNversion 中直接启动
cd ./CNversion
./sstimap.cmd --help

# 查看版本
./sstimap.cmd --version
```

根目录的 `-cn` 必须是首个参数；在 `CNversion` 目录直接调用时无需添加。

## 主要参数

| 类别 | 常用参数 | 说明 |
| --- | --- | --- |
| 目标 | `-u`、`-i`、`--load-urls`、`--load-forms` | 单目标、交互模式或文件输入 |
| 请求 | `-M`、`-P`、`-d`、`-H`、`-C`、`-m` | 标记、注入点、请求体、请求头和方法 |
| 网络 | `-a`、`-A`、`--delay`、`-p`、`--verify-ssl` | User-Agent、延迟、代理和证书验证 |
| 爬取 | `-c`、`-f`、`--crawl-exclude` | 深度、表单和排除规则 |
| 检测 | `-l`、`-e`、`-r`、`--blind-delay` | 等级、模板引擎、技术和盲注延迟 |
| 操作 | `-t`、`-T`、`-x`、`-X`、`-s`、`-S` | 模板、语言和系统交互入口 |
| 文件 | `-U`、`-D`、`-F` | 上传、下载和覆盖控制 |

## 交互模式

```powershell
./sstimap.cmd -cn -i
```

使用 `help` 查看中文命令说明，使用 `set` 查看或修改配置，使用 `run` 或 `check` 开始检测。`tpl_shell`、`eval_shell`、`os_shell`、`upload`、`download`、`reload` 和 `exit` 等命令名保持英文，便于与上游文档和脚本兼容。

## 常用流程与示例

```powershell
# URL 参数检测
./sstimap.cmd -cn -u "http://127.0.0.1:5000/?name=*"

# POST 请求体检测
./sstimap.cmd -cn -u "http://127.0.0.1:5000/render" -d "name=*" -m POST

# 限定 Jinja2 和渲染/报错技术
./sstimap.cmd -cn -u "http://127.0.0.1:5000/?name=*" -e jinja2 -r RE

# 爬取并扫描表单
./sstimap.cmd -cn -u "http://127.0.0.1:5000/" -c 2 -f
```

## 输出

控制台显示中文检测进度、插件命中和能力说明；模板引擎名、载荷、目标响应及文件内容保持原样。`--log-response` 将 HTTP 响应写入 `.sstimap/sstimap.log`，`--save-urls` 与 `--save-forms` 保存爬取结果。

## 汉化边界

参数、交互命令、插件类名、模板引擎名、HTTP 字段、模板表达式、系统命令、正则和匹配常量必须保持英文。许可证和第三方依赖原文也不修改。

## 故障排查

- 缺少依赖：在 CTFBox 根目录执行 `py -3 -m pip install -r ./CNversion/SSTImap-master/requirements.txt`。
- PowerShell 找不到命令：使用 `./sstimap.cmd -cn`，不要省略 `./`。
- 中文乱码：在 UTF-8 终端运行，必要时先执行 `chcp 65001`。
- 没有目标：提供 `-u`、`--load-urls`、`--load-forms` 或 `-i`。
- 直接调用报 `-cn` 未知：`CNversion` 的启动器已经固定为汉化版，移除 `-cn`。
- 检测结果波动：增加 `--delay`、布尔样本数和盲注验证延迟，并检查响应日志。
