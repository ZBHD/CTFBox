# SQLmap 汉化版使用说明

## 版本与目录

本目录是 SQLmap 1.10 的完整简体中文副本。命令参数、SQL 载荷、协议字段和技术名称保持原样，帮助、交互提示、日志、错误及应用说明显示中文。

## 安装环境

安装 Python 3，并确认 `py -3 --version` 或 `python --version` 可用。常用功能使用副本内置依赖，无需引用 `Original`。

## 启动

```powershell
# 从 CTFBox 根目录选择汉化版
./sqlmap.cmd -cn --help
./sqlmap.cmd -cn -hh

# 在 CNversion 目录直接启动汉化版
cd ./CNversion
./sqlmap.cmd --help

# 直接运行汉化源码
py -3 ./sqlmap-1.10/sqlmap.py --help
```

根目录的 `-cn` 必须放在首个参数位置，分发器会移除它，再把其余参数原样交给汉化版。

## 主要参数

| 类别 | 常用参数 | 说明 |
| --- | --- | --- |
| 目标 | `-u`、`-r`、`-m` | URL、HTTP 请求文件、批量目标文件 |
| 请求 | `--data`、`--cookie`、`--headers`、`--proxy` | 构造和转发 HTTP 请求 |
| 检测 | `-p`、`--level`、`--risk`、`--technique` | 选择参数、覆盖面、风险和注入技术 |
| 数据库 | `--dbms`、`--banner`、`--current-user` | 限定或识别后端数据库 |
| 枚举 | `--dbs`、`--tables`、`--columns`、`--schema` | 枚举数据库结构 |
| 导出 | `--dump`、`--dump-all`、`--output-dir` | 导出并指定结果目录 |
| 运行 | `--batch`、`-v 0-6`、`--flush-session` | 交互默认值、日志等级和会话缓存 |

完整参数使用 `./sqlmap.cmd -cn -hh` 查看，参数拼写仍为英文。

## 常用流程与示例

```powershell
# 基础检测
./sqlmap.cmd -cn -u "http://127.0.0.1/item.php?id=1" --batch

# 指定检测参数
./sqlmap.cmd -cn -u "http://127.0.0.1/item.php?id=1" -p id --level 3 --risk 2 --batch

# 从请求文件读取
./sqlmap.cmd -cn -r ./request.txt --batch

# 枚举结构
./sqlmap.cmd -cn -u "http://127.0.0.1/item.php?id=1" --dbs --batch
./sqlmap.cmd -cn -u "http://127.0.0.1/item.php?id=1" -D app --tables --batch
./sqlmap.cmd -cn -u "http://127.0.0.1/item.php?id=1" -D app -T users --columns --batch
```

## 输出

控制台显示中文状态和错误信息，目标返回的数据、数据库名、表名及字段值保持原样。默认输出目录会在启动日志中显示，也可使用 `--output-dir` 设置。`-t FILE` 可保存 HTTP 流量，`--results-file` 可设置多目标结果文件。

## 汉化边界

以下项目按设计保留英文：所有参数名、交互命令、数据库及模板引擎名称、HTTP 头、SQL 关键字、载荷、正则表达式、路径、编码名、目标返回值、许可证和第三方依赖文本。这些内容参与协议、检测或程序逻辑，翻译会改变行为。

## 故障排查

- PowerShell 找不到命令：确认位于 `D:\Projects\CTFBox`，使用 `./sqlmap.cmd -cn`。
- 中文乱码：使用 Windows Terminal，并执行 `chcp 65001` 后重试。
- 显示英文技术词：先对照“汉化边界”；普通英文提示可记录完整命令和输出以便补充词条。
- 参数报错：`-cn` 只属于根目录分发器，直接在 `CNversion` 中启动时不要添加它。
- 请求超时或响应波动：调整 `--timeout`、`--retries`、`--delay` 和线程数。
- 需要重跑检测：使用 `--flush-session` 清理当前目标会话，或指定新的输出目录。
