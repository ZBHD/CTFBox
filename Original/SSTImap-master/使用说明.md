# SSTImap 原版使用说明

## 版本与目录

本目录保存 SSTImap 原版源码，供源码参考和英文界面运行。除本说明外，目录中的原版文件保持不变。

## 安装环境

```powershell
py -3 -m pip install -r ./Original/SSTImap-master/requirements.txt
```

主要依赖包括 `requests`、`urllib3`、`beautifulsoup4` 和 `colorama`。建议在 Python 虚拟环境中安装。

## 启动

```powershell
# 从 CTFBox 根目录启动原版
./sstimap.cmd --help

# 直接运行原版源码
py -3 ./Original/SSTImap-master/sstimap.py --help

# 查看版本
./sstimap.cmd --version
```

根目录启动器默认进入本原版；首个参数为 `-cn` 时进入汉化版。

## 目标与请求参数

| 参数 | 说明 |
| --- | --- |
| `-u URL` | 指定目标 URL |
| `-i` | 进入交互模式 |
| `--load-urls FILE` | 从文件加载 URL |
| `--load-forms FILE` | 从文件加载表单 |
| `-M MARKER` | 设置注入标记，默认 `*` |
| `-P QBHC` | 选择 Query、Body、Header、Cookie 注入点 |
| `-d DATA` | 添加请求体数据，可重复使用 |
| `-H HEADER` | 添加请求头，可重复使用 |
| `-C COOKIE` | 添加 Cookie，可重复使用 |
| `-m METHOD` | 设置 HTTP 方法 |
| `-p PROXY` | 设置代理 |
| `--delay SECONDS` | 设置请求间隔 |

## 爬取与检测参数

| 参数 | 说明 |
| --- | --- |
| `-c DEPTH` | 设置爬取深度 |
| `-f` | 扫描页面表单 |
| `--crawl-exclude REGEX` | 排除匹配的 URL |
| `-l LEVEL` | 设置转义检测等级 1-5 |
| `-e ENGINE` | 限定模板引擎 |
| `-r REBT` | 选择渲染、报错、布尔盲注和时间盲注技术 |
| `--blind-delay SECONDS` | 设置时间盲注检测延迟 |
| `--generic` | 尝试通用模板引擎载荷 |
| `--legacy` | 包含旧版引擎载荷 |

## 交互模式

```powershell
./sstimap.cmd -i
```

进入后使用 `help` 查看命令，使用 `set` 配置目标和请求选项，使用 `run` 或 `check` 开始检测。常用命令包括 `tpl_shell`、`eval_shell`、`os_shell`、`upload`、`download`、`reload` 和 `exit`；命令名称保持英文。

## 常用流程与示例

```powershell
# 基础检测
./sstimap.cmd -u "http://127.0.0.1:5000/?name=*"

# 指定请求体和注入标记
./sstimap.cmd -u "http://127.0.0.1:5000/render" -d "name=*" -m POST

# 限定模板引擎和检测技术
./sstimap.cmd -u "http://127.0.0.1:5000/?name=*" -e jinja2 -r RE

# 爬取页面并扫描表单
./sstimap.cmd -u "http://127.0.0.1:5000/" -c 2 -f
```

## 输出与日志

控制台按级别显示检测进度、命中的插件和可用能力。使用 `--log-response` 可把 HTTP 响应写入用户目录下的 `.sstimap/sstimap.log`。爬取结果可通过 `--save-urls` 和 `--save-forms` 保存。

## 故障排查

- 缺少模块：重新执行 `py -3 -m pip install -r requirements.txt`。
- PowerShell 不识别命令：在 CTFBox 根目录使用 `./sstimap.cmd`。
- 没有目标：使用 `-u`、`--load-urls`、`--load-forms` 或 `-i` 中任一种。
- HTTPS 证书问题：测试环境可按帮助说明决定是否启用 `--verify-ssl`。
- 响应不稳定：增加 `--delay`，调整布尔匹配样本和盲注延迟。
- 需要更详细日志：检查 `.sstimap/sstimap.log`，并保留完整启动参数便于复现。
