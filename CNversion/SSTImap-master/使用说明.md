# SSTImap 汉化版使用说明

本目录是 SSTImap 的完整简体中文副本，可以独立于 `Original` 运行。帮助、检测进度和提示显示中文；参数名、交互命令、模板引擎、模板表达式和目标返回内容保持原样。

示例中的 `TARGET_URL` 表示你自己的 CTF 靶场或测试地址。

## 1. 启动汉化版

在 CTFBox 根目录运行：

```powershell
# 查看帮助
.\sstimap.cmd -cn -h

# 查看版本
.\sstimap.cmd -cn -V
```

`-cn` 必须是第一个参数。直接进入 `CNversion` 目录运行时不需要它：

```powershell
cd .\CNversion
.\sstimap.cmd -h
```

GUI 用户选择“SSTImap → 汉化版”即可。Windows 安装版已包含 Python 和依赖。

## 2. 如何指定注入位置

### 推荐：在目标值中放入 `*`

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*"
```

SSTImap 会在 `*` 位置插入检测内容。需要自定义标记时：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=INJECT" -M INJECT
```

### 请求中没有标记时使用 `-P`

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=test" -P Q
```

- `Q`：URL 查询参数。
- `B`：请求体。
- `H`：请求头。
- `C`：Cookie。

例如 `-P QB` 同时检查查询参数和请求体。已经放置 `*` 时通常不需要再使用 `-P`。

## 3. 示例一：URL 参数检测

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*"
```

运行后按顺序确认：

1. 目标是否可以访问。
2. 标记位置是否进入响应或模板上下文。
3. 工具是否识别出模板引擎。
4. 回显列出了哪些检测技术和可用能力。

无法修改 URL 参数值时：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=test" -P Q
```

## 4. 示例二：POST 表单检测

请求体中直接放置标记：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -m POST -d "name=*"
```

多个字段：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -m POST -d "name=*" -d "action=preview"
```

没有标记时检查全部请求体参数：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -m POST -d "name=test" -P B
```

GUI 中选择 `POST`，在“请求数据”中每行填写一个 `-d` 参数，顶部命令会同步更新。

## 5. 示例三：Cookie 和请求头

携带登录 Cookie：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" -C "session=TARGET_SESSION"
```

测试 Cookie 值：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -C "profile=*"
```

测试请求头：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -H "X-Display-Name: *"
```

回显如果显示登录页或权限不足，先更新 Cookie，再继续检测。

## 6. 示例四：已知模板引擎

已判断后端使用 Jinja2：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" -e jinja2
```

只测试渲染和报错技术：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" -e jinja2 -r RE
```

技术代码：

- `R`：渲染结果检测。
- `E`：报错检测。
- `B`：布尔盲测。
- `T`：时间盲测。

不知道模板引擎时不要填写 `-e`。目标较慢时，可先使用 `-r RE`，确认需要后再增加盲测。

## 7. 示例五：爬取并扫描表单

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -c 2 -f
```

排除退出路径并保存结果：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL" -c 2 -f --crawl-exclude "logout|signout" --save-urls .\urls.txt --save-forms .\forms.txt
```

`-c 2` 表示爬取深度为两层，`-f` 扫描发现的表单。范围越大，请求越多。

## 8. 交互模式

```powershell
.\sstimap.cmd -cn -i
```

进入后输入 `help` 查看中文说明；使用 `set` 查看或修改配置，使用 `run` 或 `check` 启动检测。`help`、`set`、`run` 等命令名保持英文。

带目标直接进入并运行：

```powershell
.\sstimap.cmd -cn -i --run -u "TARGET_URL?name=*"
```

GUI 中可从终端底部发送交互输入。

## 9. 日志和稳定性

保存 HTTP 响应：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" --log-response
```

日志通常位于用户目录的 `.sstimap\sstimap.log`。

降低请求速度：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" --delay 1
```

单独测试时间盲测并调整延迟：

```powershell
.\sstimap.cmd -cn -u "TARGET_URL?name=*" -r T --blind-delay 5 --verify-blind-delay 30
```

## 10. 汉化范围

以下内容保留英文：

- 命令行参数和交互命令。
- 模板引擎、插件和语言名称。
- HTTP 字段、模板表达式和载荷。
- 文件路径、正则表达式和目标返回值。
- 许可证与第三方依赖文本。

这些内容参与程序逻辑或需要与上游文档兼容。

## 11. 常见问题

### 提示 `-cn` 是未知参数

只有根目录 `sstimap.cmd` 使用 `-cn`。直接运行 `CNversion\sstimap.cmd` 或 `sstimap.py` 时移除它。

### 中文乱码

GUI 使用 UTF-8。命令行建议使用 Windows Terminal，必要时先运行：

```powershell
chcp 65001
```

### 没有发现测试位置

优先把 `*` 放入实际目标值。不能添加标记时，根据位置使用 `-P Q`、`-P B`、`-P H` 或 `-P C`。

### POST 请求不正确

确认已选择 `-m POST`，每个请求体字段都使用一个 `-d`。JSON 或 XML 还要设置 `--data-type` 和正确请求头。

### 检测结果不稳定

增加 `--delay`，先限制为 `-r RE`。只有确实需要盲测时再调整布尔样本和盲测延迟。
