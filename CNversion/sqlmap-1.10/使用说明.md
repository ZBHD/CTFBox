# SQLmap 汉化版使用说明

本目录是 SQLmap 1.10 的完整简体中文副本，可以独立于 `Original` 运行。帮助、状态、提示和错误信息显示中文；参数名、SQL 载荷、HTTP 字段、数据库对象和目标返回值保持原样。

示例中的 `TARGET_URL` 表示你自己的 CTF 靶场或测试地址，其他 `TARGET_*` 名称必须替换为实际值。

## 1. 安装与启动汉化版

在 CTFBox 根目录运行：

```powershell
# 基本帮助
.\sqlmap.cmd -cn -h

# 完整参数
.\sqlmap.cmd -cn -hh

# 查看版本
.\sqlmap.cmd -cn --version
```

`-cn` 是 CTFBox 启动器的版本选择参数，必须放在第一位。它会在启动 SQLmap 前被移除。

在 `CNversion` 目录内可以直接运行汉化版，不需要 `-cn`：

```powershell
cd .\CNversion
.\sqlmap.cmd -h
```

GUI 用户只需选择“SQLmap → 汉化版”。

## 2. 示例一：检测 URL 参数

假设 `TARGET_URL` 中要测试的参数是 `id`：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --batch
```

运行时依次查看：

1. 目标是否正常连接。
2. `id` 是否为动态参数。
3. 回显是否确认参数存在注入。
4. SQLmap 识别出的数据库类型和检测技术。

`--batch` 会自动采用默认答案。希望手动回答每个问题时移除该参数，并在 GUI 终端底部发送输入。

页面不稳定时使用：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --delay 1 --timeout 20 --retries 3 --batch
```

## 3. 示例二：检测 POST 或 JSON 参数

普通表单：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" --method POST --data "username=test&password=test" -p username --batch
```

JSON 请求：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" --method POST --data '{"id":1,"name":"test"}' --headers "Content-Type: application/json" -p id --batch
```

在 GUI 中填写“目标 URL”“请求方法”“请求数据”和“测试参数”后，顶部会立即生成同等命令。点击运行前先检查引号内的数据是否完整。

## 4. 示例三：带 Cookie 或令牌检测

Cookie 登录状态：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" --cookie "session=TARGET_SESSION" -p id --batch
```

Bearer Token：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" --headers "Authorization: Bearer TARGET_TOKEN" -p id --batch
```

如果回显显示跳转到登录页或每次响应完全相同，先更新 Cookie 或 Token。登录状态失效时，提高检测等级通常没有帮助。

## 5. 示例四：使用抓包请求文件

把完整 HTTP 请求保存为 `request.txt`：

```http
POST /TARGET_PATH HTTP/1.1
Host: TARGET_HOST
Content-Type: application/x-www-form-urlencoded
Cookie: session=TARGET_SESSION

id=1&name=test
```

运行：

```powershell
.\sqlmap.cmd -cn -r .\request.txt -p id --batch
```

请求文件适合处理复杂路径、多个请求头、JSON 数据和登录状态。文件中的 `Host`、空行和请求体不能省略。

## 6. 示例五：完整枚举流程

只有检测确认存在注入后才执行以下步骤。

### 枚举数据库

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --dbs --batch
```

从回显中选出数据库名并替换 `TARGET_DB`。

### 枚举数据表

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id -D TARGET_DB --tables --batch
```

### 枚举字段

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id -D TARGET_DB -T TARGET_TABLE --columns --batch
```

### 读取指定字段

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id -D TARGET_DB -T TARGET_TABLE -C TARGET_COLUMN --dump --batch
```

只读取前 20 行：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id -D TARGET_DB -T TARGET_TABLE --dump --start 1 --stop 20 --batch
```

GUI 会保留每次运行的命令与回显。当前版本尚未自动解析真实回显并填充数据库、表和字段下拉项，因此请从终端复制名称并手动填写。

## 7. 检测等级与技术

默认检测没有结论时，可逐步增加覆盖面：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --level 3 --risk 2 --batch
```

- `--level 1-5` 控制测试覆盖面。
- `--risk 1-3` 控制测试强度。
- `--technique BEUSTQ` 限制注入技术。
- `--dbms` 在已知数据库类型时缩小范围。

例如仅测试布尔、报错和联合查询，并限定 MySQL：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --technique BEU --dbms MySQL --batch
```

## 8. 会话和输出

完整重测当前目标：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --flush-session --batch
```

保存 HTTP 流量并提高日志详细度：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id -v 3 -t .\traffic.txt --batch
```

把结果写到指定目录：

```powershell
.\sqlmap.cmd -cn -u "TARGET_URL" -p id --output-dir .\sqlmap-output --batch
```

数据库名、表名、字段名和目标数据不会翻译，便于复制到下一条命令。

## 9. 故障排查

### 提示 `-cn` 是未知参数

你可能直接运行了 `sqlmap.py` 或 `CNversion\sqlmap.cmd`。只有根目录的统一启动器需要 `-cn`。

### 中文乱码

GUI 使用 UTF-8。命令行建议使用 Windows Terminal，必要时先运行：

```powershell
chcp 65001
```

### 部分内容仍是英文

参数、载荷、协议字段、数据库内容、路径、编码名和第三方依赖文本按设计保留英文，它们参与工具逻辑或需要与上游兼容。

### 参数被判断为静态

检查登录状态和目标参数是否真的影响响应。复杂请求优先使用 `-r request.txt`。

### 结果似乎来自上一次运行

增加 `--flush-session` 清除当前目标会话，或使用 `--fresh-queries` 忽略缓存查询。
