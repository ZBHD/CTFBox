本次更新将 Misc 中的 LSB 隐写和图片/文件隐写从基础文件选择界面升级为可实际执行的本地分析工作台。分析、解码、频域计算、DCT 统计和文件雕刻均由 CTFBox 内置代码完成，运行时不依赖用户另外安装隐写分析软件。

## 二、主要更新

### 2.1 LSB 隐写工作台

LSB 模块同时保留自动分析和手动提取两种工作方式。

- 自动分析支持快速扫描和深度扫描，并按证据强度对候选结果排序。
- 支持 R、G、B、A 和调色板索引通道的 0-7 位平面组合。
- 支持逐行、逐列、左右反向、上下反向、蛇形扫描和像素序反转。
- 支持 MSB/LSB 位打包、位偏移、字节偏移、字节反转和位反相。
- 支持像素交错与通道分块布局。
- 自动识别连续可打印文本、常见文件头和疑似 Flag。
- 支持 ZIP、GZIP 等结果的文件雕刻，并继续检查归档内部文本和 Flag。
- 使用独立 Worker 执行搜索，支持取消任务并保留不同工具的独立结果状态。

原始验收题 `misc53.png`、`misc54.png`、`misc55.png` 和 `misc56.png` 已通过真实 CTFBox 界面完成提取。其中包含通道组合、扫描变换、归档雕刻和归档内 Flag 等不同链路。

### 2.2 Flag 一键复制

LSB 候选结果识别到以下任一证据时，会在候选详情右上角显示复制按钮：

- 发现 Flag
- 疑似 Flag
- 归档内发现 Flag
- 归档内发现疑似 Flag

按钮位于“应用参数”左侧，复制的是结构化证据中的完整 Flag，而不是候选列表里可能被截断的预览文本。复制成功后按钮切换为勾选状态。真实界面验收已确认内容能够写入 Windows 系统剪贴板。

### 2.3 图片与文件隐写工作台

新增独立的图片/文件隐写分析任务和七个结果视图：总览、元数据、结构、字符串、可视化、DCT 和雕刻文件。

#### 文件结构与附加数据

- 识别 PNG、JPEG、GIF、BMP、RIFF 和 PDF 的主要结构。
- 计算规范文件结束位置，检测并雕刻尾部附加数据。
- 解析 PNG 块，校验块长度和 CRC，并标记私有块。
- 解析 JPEG 标记段、APP 段和注释段。

#### 元数据

- 提取 PNG `tEXt`、`zTXt`、`iTXt`、`eXIf` 和 `iCCP`。
- 提取 JPEG EXIF、XMP、ICC、APP13 和 COM。
- 使用带边界检查的 TIFF IFD 解析器读取常见 EXIF 和 GPS 标签。

#### 字符串与编码

- 扫描 ASCII、UTF-8、UTF-16LE、UTF-16BE 和 GB18030 字符串。
- 对疑似 Base64、Hex 和 URL 编码内容执行二次解码。
- 使用全局 Flag 检测头检查原始文本和二次解码结果。

#### 像素与频域

- 生成 R、G、B、A、灰度、反相灰度和自动对比度拉伸视图。
- 生成灰度 0-7 位平面，总计十五种像素视图。
- 使用内置二维 FFT 生成中心化幅度谱、频带能量占比和非 DC 峰值。

#### JPEG DCT

- 解码基线 JPEG Huffman 熵流和量化 DCT 系数。
- 统计图像分量、DCT 块数、AC 零值率及 64 个 Zig-zag 位置的奇偶分布。
- 对渐进式 JPEG 和算术编码 JPEG 返回明确的不支持状态，避免输出伪造统计结果。

## 三、能力边界

CTFBox 1.1.2 的目标是覆盖常见和多数中等难度图片隐写题，并为复杂题提供可复核的结构、字符串、像素、频域和 DCT 证据。以下情况可能只产生候选证据，不能直接得到最终 Flag：

- 题目使用未公开或题目专用的自定义嵌入、加密或校验算法。
- 最终答案依赖多个文件、题目描述、网络资源或人工语义推断。
- JPEG 使用 F5、OutGuess、Steghide 等需要专用算法或口令的完整解码流程。
- 数据经过多阶段变换，且变换顺序超出当前自动搜索空间。
- 文件损坏程度超过浏览器图片解码器和内置容器解析器的容错范围。

因此，频域异常、DCT 奇偶分布或可疑字符串应视为分析证据，而不是最终答案保证。

## 四、界面与任务体验

- LSB 和图片/文件隐写使用独立任务类型，切换工具不会覆盖彼此结果。
- 分析参数、进度、候选和结果页均使用结构化状态，不拼接执行外部 Shell 命令。
- 结果区域支持横向页签滚动和内部内容滚动。
- 已验收 1280、800 和 480 像素宽度，无页面横向溢出和工作区重叠。
- 深色、浅色主题均完成界面检查。

## 七、升级说明

1. 退出正在运行的旧版 CTFBox。
2. 运行 `CTFBox_1.1.2_x64-setup.exe`。
3. 按安装程序提示选择安装目录并完成安装。
4. 启动后进入“设置 → 版本更新”，确认当前版本显示为 `v1.1.2`。
5. 打开 Misc，可分别选择 LSB 隐写或图片/文件隐写工作台。

升级不会主动清除已经保存在本机的主题和 Flag 检测头设置。正在运行的临时任务不会跨应用重启恢复，升级前应先保存需要保留的输出。
