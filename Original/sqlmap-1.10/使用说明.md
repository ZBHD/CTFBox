# SQLmap 原版使用说明

## 版本与目录

本目录保存 SQLmap 1.10 原版源码，供源码参考和英文界面运行。除本说明外，目录中的原版文件不参与汉化修改。

## 安装环境

1. 安装 Python 3，并确认 `py -3 --version` 或 `python --version` 可用。
2. SQLmap 的常用功能使用仓库内置依赖，无需额外执行 `pip install`。
3. 在 PowerShell 中进入 `D:\Projects\CTFBox`；当前目录命令需要带 `./` 前缀。

## 启动

```powershell
# 从 CTFBox 根目录启动原版
./sqlmap.cmd --help

# 直接运行原版源码
py -3 ./Original/sqlmap-1.10/sqlmap.py --help

# 查看完整参数
./sqlmap.cmd -hh

# 查看版本
./sqlmap.cmd --version
```

根目录启动器默认进入本原版。只有首个参数是 `-cn` 时才会进入汉化版。

## 目标与请求参数

| 参数 | 说明 |
| --- | --- |
| `-u URL` | 指定单个目标 URL |
| `-r FILE` | 从文本文件读取完整 HTTP 请求 |
| `-m FILE` | 从文件批量读取多个目标 |
| `--data DATA` | 指定 POST 请求体 |
| `--cookie COOKIE` | 指定 Cookie |
| `--headers HEADERS` | 指定额外请求头 |
| `--method METHOD` | 指定 HTTP 方法 |
| `--proxy URL` | 通过代理发送请求 |
| `--random-agent` | 随机选择 User-Agent |
| `--delay SECONDS` | 设置请求间隔 |
| `--timeout SECONDS` | 设置请求超时 |

## 检测参数

| 参数 | 说明 |
| --- | --- |
| `-p PARAM` | 只测试指定参数，多个参数用逗号分隔 |
| `--level 1-5` | 控制测试覆盖面 |
| `--risk 1-3` | 控制可能影响目标的测试强度 |
| `--technique BEUSTQ` | 选择布尔、报错、联合、堆叠、时间和内联技术 |
| `--dbms NAME` | 已知后端数据库时限定 DBMS |
| `--tamper NAME` | 加载篡改脚本，可用逗号连接多个脚本 |
| `--batch` | 对交互问题采用默认答案 |

## 枚举与输出参数

| 参数 | 说明 |
| --- | --- |
| `--banner` | 获取数据库管理系统标识 |
| `--current-user` | 获取当前数据库用户 |
| `--current-db` | 获取当前数据库 |
| `--dbs` | 枚举数据库 |
| `--tables -D DB` | 枚举指定数据库中的表 |
| `--columns -D DB -T TABLE` | 枚举指定表的列 |
| `--dump -D DB -T TABLE` | 导出指定表的数据 |
| `--schema` | 枚举数据库结构 |
| `--output-dir DIR` | 指定结果目录 |
| `-v 0-6` | 设置日志详细程度 |

## 常用流程与示例

以下示例使用本地占位地址，执行时替换为自己的 CTF 或测试环境。

```powershell
# 基础检测
./sqlmap.cmd -u "http://127.0.0.1/item.php?id=1" --batch

# 指定参数和检测等级
./sqlmap.cmd -u "http://127.0.0.1/item.php?id=1" -p id --level 3 --risk 2 --batch

# 从抓包保存的请求文件读取目标
./sqlmap.cmd -r ./request.txt --batch

# 枚举数据库、表和列
./sqlmap.cmd -u "http://127.0.0.1/item.php?id=1" --dbs --batch
./sqlmap.cmd -u "http://127.0.0.1/item.php?id=1" -D app --tables --batch
./sqlmap.cmd -u "http://127.0.0.1/item.php?id=1" -D app -T users --columns --batch
```

## 输出位置

默认结果通常写入用户目录下的 `.local/share/sqlmap/output` 或平台对应的数据目录。启动日志会显示实际输出路径；也可用 `--output-dir` 明确指定。会话数据库用于续跑，`--flush-session` 可清理当前目标的缓存结论。

## 故障排查

- 显示找不到 Python：安装 Python 3，或把 `python.exe` 加入 `PATH`。
- PowerShell 不识别 `sqlmap.cmd`：使用 `./sqlmap.cmd`，并确认当前目录是 `D:\Projects\CTFBox`。
- 请求参数未识别：先运行 `./sqlmap.cmd -hh`，参数名保持英文。
- 中文终端乱码不影响本原版；汉化界面请使用 `./sqlmap.cmd -cn` 并将终端切换为 UTF-8。
- 目标响应不稳定：适当增加 `--timeout`、`--retries` 和 `--delay`，并降低并发。
- 需要确认实际请求：使用 `-v 3` 或更高日志等级，也可配合 `-t traffic.txt` 保存 HTTP 流量。
